## How to use?

### 1. Run the .exe file

### 2. Select the folder of your KiCad project

### 3. Click the Generate button

### 4. Open your Project folder to see the documents generated

The documents include:
1. Schematics.
1. PCB.
1. Bill of Materials (BoM).
1. 3D Renders (different angles).
1. The full project .pdf containing all above files in one.
